# JavaScript course — source and licence notes

The lesson prose, analogies, examples, quizzes and exercises in this course are original to
Untiered. No lesson text or example was copied from a tutorial site, book, course, or
interview-question repository. The full research note, with every licence as read and the
reasons for each decision below, is `docs/javascript-course-research.md` (29 October 2026).
